# 华夏拼图 - 中国地理益智游戏

> 一款通过完成拼图认识中国各省标志性建筑和景点的益智游戏

## 📁 文件结构

```
china-puzzle/
├── public/
│   ├── index.html          # 游戏主页面（完整单页应用）
│   └── images/              # 景点图片目录
│       ├── 北京-故宫.jpg
│       ├── 北京-长城.jpg
│       ├── 北京-天坛.jpg
│       ├── 上海-外滩.jpg
│       └── ... (共99张景点图片)
├── src/                    # Next.js 源码（可选，用于SSR）
├── package.json
└── README.md               # 本文档
```

## 🚀 快速部署

### 方式一：直接部署静态文件（推荐）

1. 将 `public/index.html` 和 `public/images/` 目录部署到任意静态服务器
2. 支持 Nginx、Apache、Caddy、GitHub Pages 等任何静态服务器

**Nginx 配置示例：**
```nginx
server {
    listen 80;
    server_name your-domain.com;
    root /path/to/china-puzzle/public;
    index index.html;
    
    # 启用Gzip压缩
    gzip on;
    gzip_types text/plain text/css application/json application/javascript;
    
    # 图片缓存
    location /images/ {
        expires 30d;
        add_header Cache-Control "public, immutable";
    }
}
```

**启动本地服务器：**
```bash
# Python 3
cd public
python -m http.server 8080

# Node.js
npx serve public

# PHP
cd public
php -S localhost:8080
```

### 方式二：Next.js 项目（已配置）

```bash
# 安装依赖
pnpm install

# 开发模式
pnpm dev

# 生产构建
pnpm build
pnpm start
```

## 🎮 游戏功能

### 核心玩法
- **三种难度**：简单(4×6=24片)、中等(6×8=48片)、困难(10×15=150片)
- **34个省份**：覆盖中国所有省份及港澳台
- **102个景点**：每个省份3个标志性景点
- **拖动操作**：选择下方拼图碎片，拖动或点击放置到拼图板

### 游戏特色
- ✅ 拼图碎片滑动选择，左右滑动浏览
- ✅ 触摸拖拽支持，移动端友好
- ✅ 实时计时和步数统计
- ✅ 原图预览功能
- ✅ 完成进度自动保存

### 道具系统
| 道具 | 价格 | 功能 |
|------|------|------|
| 💡 提示卡 | 20🪙 | 显示一个正确位置 |
| 👁 透视镜 | 50🪙 | 显示全部位置5秒 |
| 🛡️ 保护罩 | 30🪙 | 一次错误不扣分 |
| ❄️ 时间冻结 | 40🪙 | 暂停计时30秒 |
| ↩️ 撤销卡 | 15🪙 | 撤销最近操作 |
| 💣 炸弹 | 25🪙 | 随机打乱3块 |

### 金币系统
- 完成拼图获得金币奖励（根据难度30-120不等）
- 金币用于购买道具
- 观看广告可获得道具

### 解锁机制
- 每个省份需先完成第1个景点才能解锁第2个
- 完成前两个才能解锁第3个
- 未解锁景点显示灰色锁定状态

## 🎮 快速开始

1. 下载所有文件
2. 确保 `index.html` 和 `images/` 目录在同一目录下
3. 用浏览器打开 `index.html`
4. 输入昵称开始游戏

## 💡 提示

- 游戏进度会自动保存在浏览器本地存储中
- 清除浏览器数据会导致游戏进度丢失
- 建议使用 Chrome、Safari、Firefox 或 Edge 浏览器的最新版本
